# 插件使用指南

SPlayer-Next 支持通过插件扩展**音源**（解析歌曲的播放地址）与**控制**（联动播放状态、反向控制播放）。本文面向最终用户，介绍如何安装、启用与管理插件。想自己写插件，见 [插件开发](/plugins/)。

## 打开插件管理

**设置 → 插件管理**。每个已安装插件以卡片展示：名称、版本、作者、运行状态与支持的音源。

## 安装插件

可选择以下方式：

- **插件市场**：在插件市场中选择插件并点击安装。
- **本地导入**：选择一个 `.js` 脚本文件。
- **在线导入**：粘贴一个指向 `.js` 脚本的 HTTPS 链接（如 GitHub / Gitee 的 raw 地址）。

LX 脚本及压缩脚本的支持范围见 [LX 兼容](/plugins/lx)。

## 启用 / 禁用 / 卸载

- 新安装的插件会**自动启用**。
- 在卡片上可随时启用或禁用插件；可同时启用多个插件（含多个音源），当多个插件支持同一音源时，由 SPlayer-Next 按优先级自动选用。
- 插件若声明了设置项，可在卡片上打开**设置**进行配置。
- **卸载**会删除脚本及其本地数据，且不可恢复。

状态徽章：**已就绪**（可用）、**加载中**、**错误**（卡片下方会显示原因）、**已禁用**。

## 查看详情与管理权限

点击已安装插件的卡片，打开详情弹窗。在「权限」中可逐项开启或关闭插件申请的权限：

| 权限       | 允许插件做什么                                                   |
| ---------- | ---------------------------------------------------------------- |
| 网络请求   | 请求外部网络服务                                                 |
| 播放控制   | 播放、暂停、切歌和修改播放队列                                   |
| 界面扩展   | 添加菜单和发送系统通知                                           |
| 音乐库访问 | 搜索本地音乐库                                                   |
| 平台接口   | 使用软件当前的平台登录状态调用接口，包括收藏、修改歌单等账号操作 |

插件声明的权限默认开启，可在详情中关闭；更新插件会保留你的选择。

## 常见问题

**导入后状态显示「错误」？**
查看卡片下方的错误信息，通常是脚本本身的语法 / 运行错误，或脚本声明的 API 级别高于当前版本（需等待应用升级）。

**插件崩溃会影响应用吗？**
插件在独立宿主进程中运行，宿主崩溃后应用会尝试重启它；期间其他插件也可能短暂不可用。

**插件请求很慢？**
插件的网络请求会遵循系统代理，速度取决于目标接口与网络状况。
